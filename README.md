# TEXTSENSE – AI-Powered Customer Feedback Analytics

**TEXTSENSE** is a full-stack web application that uses Natural Language Processing (NLP) and Machine Learning to analyze customer feedback, reviews, comments, and complaints. It identifies sentiment, extracts important keywords, and provides insights through user and administrator dashboards.

The goal is to help organizations understand customer opinions, identify recurring issues, and improve service quality through data-driven insights.

## 🎯 Project Objectives

- Analyze customer feedback automatically using NLP.
- Classify feedback as Positive, Negative, or Neutral.
- Extract important keywords from customer reviews.
- Maintain feedback records and analysis history.
- Provide dashboards for feedback management and sentiment analytics.
- Support secure authentication and role-based access.
- Help organizations understand customer satisfaction and identify areas for improvement.

## 🏗️ System Architecture

The application follows a client-server architecture in which React communicates with Django through REST APIs.

```text
User / Administrator
         |
         v
   React Frontend
         |
         v
  Django REST APIs
         |
         v
  NLP Processing
 (NLTK / spaCy)
         |
         v
 TF-IDF + Logistic Regression
         |
         v
    PostgreSQL
         |
         v
 Analysis Results and Dashboards
```

## 🔄 How It Works

1. The user registers or logs in to the application.
2. The user submits feedback through the React interface.
3. React sends the feedback to the Django REST API.
4. Django validates the request and processes the data.
5. The NLP pipeline preprocesses the text.
6. TF-IDF converts the text into numerical features.
7. The trained classification model predicts the sentiment.
8. Important keywords are extracted from the feedback.
9. Feedback and analysis results are stored in PostgreSQL.
10. The analysis results are returned to React and displayed to the user.
11. The administrator can view aggregated feedback and sentiment analytics.

## 📊 Machine Learning Workflow

The proposed sentiment-analysis pipeline consists of the following stages:

1. Collect a labelled feedback dataset.
2. Clean the dataset and handle missing or duplicate records.
3. Preprocess the text using NLP techniques.
4. Split the dataset into training and testing sets.
5. Extract numerical features using TF-IDF.
6. Train a Logistic Regression classifier.
7. Evaluate the model using accuracy, precision, recall, F1-score, and a confusion matrix.
8. Save the trained model and vectorizer.
9. Integrate the model with Django.
10. Expose predictions through REST APIs.

## 🔐 Authentication and Authorization

The application is designed to support authentication and role-based access control.

- **General User:** Submit feedback and view personal feedback history and analysis.
- **Administrator:** Manage feedback, users, and analytics according to assigned permissions.

Backend APIs should enforce authorization to ensure users can access only the resources permitted for their roles.
